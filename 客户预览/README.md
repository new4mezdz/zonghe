# 盒模轨迹查询风格预览

下载仓库后，用现代浏览器打开 [盒模轨迹查询-三套风格预览.html](盒模轨迹查询-三套风格预览.html)，点击顶部按钮切换三种方案：

- **A · 简洁蓝白**：查询记录与检验进度位于左侧，适合日常查询。
- **B · 深色工控**：放大轨迹图，适合车间展示。
- **C · 紧凑工作台**：增加各轮编号对照表，适合频繁核查。

点击示例记录可切换七轮定位，也可输入 `MH-03001` 至 `MH-03004` 查询。一号轮仅含编号 **1、2**；三号轮示例含 1 至 8，其余轮编号范围以正式配置为准。

这些页面使用示例数据，仅用于选择界面风格，不连接业务接口。正式模块仍位于 `service/templates/boxquery.html` 及 `service/static/boxquery/`。

[源文件/mold-query-styles.html](源文件/mold-query-styles.html) 保存可编辑的页面片段；对外演示使用上方的完整预览页。GitHub 文件页面显示的是代码，下载后在浏览器中打开即可操作。
