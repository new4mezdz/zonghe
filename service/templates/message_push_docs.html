消息推送接口说明

返回消息推送 JSON说明

基础信息

这些接口用于给内网其他系统查询或写入消息推送数据库数据。所有接口返回 JSON，编码为 UTF-8。

当前访问地址：

其他电脑调用时，把地址中的 127.0.0.1 或 localhost 换成这台服务器的内网 IP，例如 http://192.168.31.58:5000。

当前接口未加登录鉴权，建议只在可信内网开放；如果后面要给外部网络调用，需要再加 token 校验。

数据字段

字段类型说明示例
idinteger数据库自增主键1
push_timestring选择的推送时间2026-05-06 14:05:00
machine_nointeger机台号，只允许 1 到 125
contentstring自定义文本内容5号机台注意检查
created_atstring提交到数据库的时间2026-05-06 14:01:23

查询列表

GET /api/message_push/messages

用于分页查询消息推送记录，所有查询参数都可以不传。

参数必填说明示例
machine_no否按机台号过滤，范围 1-125
start_time否起始时间。只传日期时自动补 00:00:002026-05-06
end_time否结束时间。只传日期时自动补 23:59:592026-05-06 18:00:00
keyword否按内容模糊搜索停机
limit否每页条数，默认 50，最大 50050
offset否分页偏移量，第 1 页为 0，第 2 页为 limit0
order否排序方式：desc 新到旧，asc 旧到新desc

请求示例


            
返回示例

            
{
  "success": true,
  "total": 1,
  "limit": 50,
  "offset": 0,

      "machine_no": 5,
      "content": "5号机台注意检查",
      "created_at": "2026-05-06 14:01:23"
    }

用于根据记录 ID 获取单条数据。

            
请求示例

新增推送

            
POST /api/message_push/submit

            
用于写入一条新的消息推送记录，请求头需要使用 Content-Type: application/json。

            

                

                    
                        
字段必填说明示例

                    
                    
                        
push_time是推送时间，支持 YYYY-MM-DDTHH:MM 或 YYYY-MM-DD HH:MM:SS2026-05-06T14:05

                        
machine_no是机台号，范围 1-125

                        
content是自定义文本内容5号机台注意检查

                    
                

            

            
curl 示例

            

            
JavaScript fetch 示例

            

            
成功返回

            
{
  "success": true,
  "message": "提交成功",
  "record": {
    "id": 1,
    "push_time": "2026-05-06 14:05:00",
    "machine_no": 5,
    "content": "5号机台注意检查",
    "created_at": "2026-05-06 14:01:23"
  }
}

        


        

            
状态码和注意事项

            
    
                
  • 200：请求成功。
    • 
                
  • 400：新增接口参数错误，例如机台号不在 1-12、时间为空、内容为空。
    • 
                
  • 404：单条详情记录不存在。
    • 
                
  • 查询接口只返回业务字段，不开放 SQLite 直连和任意 SQL 执行。
    • 
                
  • 接口已允许 CORS，内网网页系统可以直接跨端口调用。
